# SkillCraft Technology - Task 02: Data Cleaning

## 📌 Overview

This project was completed as part of my Data Analyst Internship at SkillCraft Technology.

The objective of this task was to clean and prepare a retail store sales dataset using Python and Pandas.

## 🛠️ Tools Used

- Python
- Pandas
- Jupyter Notebook

## 🔍 Data Cleaning Steps

The following steps were performed:

- Loaded and inspected the dataset
- Identified and handled missing values
- Checked for duplicate records
- Converted columns to appropriate data types
- Converted the Transaction Date column to datetime format
- Performed final data quality checks
- Exported the cleaned dataset as a CSV file

## 📂 Files

- `SCT_Task2_DataCleaning.ipynb` — Jupyter Notebook containing the complete data-cleaning process
- `Cleaned_retail_store_sales.csv` — Cleaned dataset

## 🎯 Outcome

The dataset was cleaned and prepared for further analysis while ensuring appropriate data types and handling missing values.
